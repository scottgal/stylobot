# Mostlylucid.BotDetection.Llm.LlamaSharp

Local CPU-based LLM provider for [Mostlylucid.BotDetection](https://www.nuget.org/packages/mostlylucid.botdetection) using [LLamaSharp](https://github.com/SciSharp/LLamaSharp).

Runs GGUF models on-device for bot classification without external API calls.

## Installation

```bash
dotnet add package Mostlylucid.BotDetection.Llm.LlamaSharp
```
